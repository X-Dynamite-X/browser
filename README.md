# متصفح النور الخفيف (LiteBrowser) — C++17 Cross-Platform

متصفح إنترنت خفيف وسريع مكتوب بلغة **C++17** بتحكم مباشر بالذاكرة، مصمم للعمل بكفاءة على **Linux** وجميع إصدارات **Windows** (بما في ذلك **Windows XP SP3** و **Windows 7 / 8 / 10 / 11**).

---

## المزايا الرئيسية

1. **خفيف جداً وسريع الإقلاع:**
   - حجم النسخة التنفيذية على Linux حوالي **368 كيلوبايت** فقط، وعلى Windows ملف `.exe` مستقل بحجم **1.3 - 1.4 ميجابايت** بدون الحاجة لتثبيت حزم خارجية.
   - يتضمن **الوضع الخفيف (`⚡ خفيف`)** لتقليل استهلاك الذاكرة العشوائية (RAM) والمعالج على الأجهزة الضعيفة والقديمة، مع **مانع إعلانات ومتتبعات مدمج**.
2. **قارئ مدمج لملفات PDF و Word بدون برامج خارجية:**
   - يفتح ملفات **Word الحديثة (`.docx`)** مع دعم العناوين، التنسيقات، الجداول، الروابط، الصور المضمّنة، واتجاه النص العربي (RTL).
   - يفتح ملفات **Word الكلاسيكية (`.doc` بتنسيق OLE2 Word 97-2003)** وملفات **`.rtf`** و **`.txt`** و **`.md`**.
   - يفتح ملفات **PDF (`.pdf`)** بمحرك عرض مزدوج (عرض بصري عالي الدقة عبر Poppler+Cairo على Linux + محلل PDF مدمج بلغة C++17 يعمل على كافة الأنظمة بما فيها Windows XP حتى بدون إنترنت)، مع البحث داخل المستند، التكبير/التصغير، والوضع الليلي/الورقي، والطباعة.
3. **البحث، الفيديوهات، والألعاب:**
   - شريط عنوان وبحث ذكي يدعم الروابط، المسارات المحلية، والبحث المباشر (Google / DuckDuckGo Lite الخفيف / YouTube).
   - دعم كامل للفيديو HTML5/MSE و WebGL على Linux والأنظمة الحديثة، مع صفحة مشغّل فيديو مدمجة (`lite://video`).
   - مركز ألعاب (`lite://games`) يضم روابط منصات ألعاب HTML5 الخفيفة بالإضافة إلى **3 ألعاب مدمجة تعمل فوراً حتى بدون إنترنت** (الثعبان Snake، كاسر الطوب Breakout، ولعبة 2048).
4. **مدير تحميلات البرامج والملفات (`lite://downloads`):**
   - تحميل البرامج (`.exe`, `.msi`, `.zip`, `.deb`, `.tar.gz` وغيرها) والمستندات من الإنترنت مع عرض نسبة التقدم والحجم وفتح الملف أو مجلد التحميلات.

---

## الملفات التنفيذية الجاهزة في مجلد `dist/`

تم بناء وتجهيز النسخ الثلاث مباشرة في المجلد `dist/`:

- **لأنظمة Linux (64-bit):**
  ```bash
  ./dist/litebrowser-linux-x64
  ```
  أو لفتح ملف PDF أو Word مباشرة في المتصفح:
  ```bash
  ./dist/litebrowser-linux-x64 samples/arabic_guide.docx
  ./dist/litebrowser-linux-x64 samples/sample_handbook.pdf
  ```

- **لأنظمة Windows XP / 7 / 8 / 10 / 11 (نسخة 32-بت متوافقة مع NT 5.1 فصاعداً):**
  - الملف: `dist/LiteBrowser-Win32-XP-7-8-10.exe`
  - يعمل مباشرة بنقرة مزدوجة بدون تثبيت أي مكتبات خارجية.

- **لأنظمة Windows 7 / 8 / 10 / 11 (نسخة 64-بت):**
  - الملف: `dist/LiteBrowser-Win64-7-8-10-11.exe`

> **ملاحظة اختيارية لترقية محرك العرض على Windows XP / Windows 7:**
> يعمل ملف `.exe` فوراً بمحرك النظام المدمج مع تفعيل وضع HTML5 القياسي تلقائياً. وإذا رغبت بتشغيل محرك Chromium حديث بالكامل داخل نفس المتصفح على Windows 7 أو Windows XP، يكفي وضع ملف `node.dll` الخاص بمكتبة **Miniblink** بجانب ملف `LiteBrowser.exe` وسيكتشفه المتصفح تلقائياً عند التشغيل دون إعادة بناء.

## اختصارات لوحة المفاتيح (Linux)

- `Ctrl + T`: فتح تبويب جديد
- `Ctrl + W`: إغلاق التبويب الحالي
- `Ctrl + O`: فتح ملف PDF أو Word من الجهاز
- `Ctrl + L`: تحديد شريط البحث والعنوان
- `F5`: تحديث الصفحة أو المستند
