# متصفح النور الخفيف (LiteBrowser) — C++17 Cross-Platform

متصفح إنترنت خفيف وشامل فائق السرعة مكتوب بلغة **C++17** بتحكم دقيق ومباشر بالذاكرة، مصمم ليعمل بسلاسة تامة على **Linux** وكافة أجيال **Windows**، وبشكل خاص **Windows XP (SP2/SP3 - NT 5.1)** بالإضافة إلى **Windows 7 / 8 / 10 / 11**.

---

## 🚀 المزايا الرئيسية الشاملة

### 1. خفة فائقة واستهلاك ذاكرة ضئيل (Ultra-Lightweight & Instant Launch)
- **حجم الملف التنفيذي:**
  - على **Linux**: حوالي **492 كيلوبايت** فقط!
  - على **Windows (XP / 7 / 8 / 10 / 11)**: ملف `.exe` مستقل بحجم **1.5 ميجابايت** لا يتطلب تثبيت أي برامج أو حزم خارجية.
- **تخصيص الموارد التلقائي لأنظمة Windows XP والأجهزة القديمة:**
  - يتعرف المتصفح تلقائياً على نظام التشغيل وذاكرة الجهاز (RAM). إذا كانت الذاكرة أقل من 2 جيجابايت أو كان النظام Windows XP، يُفعل "الوضع الخفيف" افتراضياً ويقوم بتفريغ صفحات الذاكرة غير المستخدمة (`SetProcessWorkingSetSize`) لضمان أقصى سرعة واستجابة.
- **مانع إعلانات ومتتبعات مدمج (Built-in AdBlocker):**
  - يحجب نطاقات الإعلانات المزعجة والمتتبعات والنوافذ المنبثقة تلقائياً لتسريع تحميل الصفحات وتوفير استهلاك البيانات.

### 2. قارئ مستندات PDF و Word متكامل داخل التبويبات (Zero-Office Required)
- يفتح المتصفح المستندات مباشرة كصفحات تصفح دون الحاجة لتثبيت Microsoft Office أو Adobe Acrobat:
  - **ملفات Word الحديثة (`.docx`):** استخراج فائق الدقة للنصوص، التنسيقات (غامق، مائل، ملون)، العناوين، الجداول مع دمج الخلايا (`gridSpan`) وخلفياتها، الصور المضمّنة (PNG/JPEG)، الروابط، الحواشي السفلية، ودعم كامل للغة العربية (RTL).
  - **ملفات Word الكلاسيكية (`.doc` Word 97-2003 OLE2):** قراءة هياكل FIB وجداول القطع النصية بنظامي الترميز UTF-16LE و ANSI.
  - **ملفات النصوص والمستندات الأخرى (`.rtf`, `.txt`, `.md`):** فك ترميز محارف Unicode ورموز التنسيق بدقة.
  - **ملفات PDF (`.pdf`):** محرك مزدوج (Poppler + Cairo عالي الدقة على Linux، ومحلل C++17 مستقل داخلياً لأنظمة Windows XP بدون أي مكتبات إضافية).
  - **أدوات عارض المستندات:** البحث داخل النص، الانتقال المباشر لأي صفحة، التدوير بزاوية 90 درجة، الوضع الليلي (Dark)، وضع القراءة الورقي (Sepia)، والطباعة.

### 3. البحث ومشاهدة الفيديوهات والألعاب
- **شريط بحث وعنوان ذكي (Omnibox):**
  - يتعرف تلقائياً على الروابط والمسارات ومحركات البحث.
  - محركات بحث متعددة قابلة للتبديل من الإعدادات: Google، DuckDuckGo، DuckDuckGo Lite، Bing، و YouTube.
- **مشاهدة الفيديوهات (`lite://video`):**
  - دعم تشغيل الفيديو الحديث HTML5 و MSE و WebAudio، مع مشغل فيديو مدمج.
- **مركز ألعاب مدمج يعمل بدون إنترنت (`lite://games`):**
  - يتضمن 3 ألعاب Canvas تفاعلية جاهزة للعب فوراً دون الحاجة لاتصال بالإنترنت:
    1. **لعبة الثعبان الكلاسيكية (Snake)** مع مستويات ونقاط.
    2. **لعبة كاسر الطوب (Breakout)** مع مستويات متعددة ومؤثرات ارتداد.
    3. **لعبة الأرقام الشهيرة 2048**.
  - روابط مباشرة لمنصات ألعاب HTML5 الخفيفة.

### 4. مدير تحميلات متطور متعدد الخيوط (`lite://downloads`)
- محرك تحميل مخصص `DownloaderPool` يعمل في خلفية البرنامج ويدعم:
  - إيقاف مؤقت للتحميل (**Pause**).
  - استئناف التحميل المتقطع (**Resume**) باستخدام ترويسات `Range: bytes=`.
  - إلغاء التحميل (**Cancel**).
  - حساب سرعة التحميل الآنية ونسبة التقدم في شريط التقدم.
  - حفظ سجل التحميلات بصيغة TSV وفتح الملفات المنزلة بنقرة واحدة.

### 5. أدوات التصفح المتقدمة وسهولة الاستخدام
- **البحث داخل الصفحة (`Ctrl + F`):** شريط بحث سريع للبحث عن أي كلمة داخل الصفحة الحالية مع زري "التالي" و"السابق" وتظليل النتائج.
- **شريط الإشارات المرجعية (`Ctrl + Shift + B`):** شريط أفقي أسفل شريط العنوان للوصول المباشر والفوري للمواقع المفضلة.
- **استعادة التبويب المغلق (`Ctrl + Shift + T`):** إمكانية استعادة آخر تبويبات تم إغلاقها بالخطأ.
- **التصفح السري / الخاص (`Ctrl + Shift + N`):** تبويب آمن مشفر لا يحفظ أي سجلات في تاريخ التصفح.
- **استعادة الجلسة السابقة (Session Restore):** إمكانية إعادة فتح التبويبات التي كانت مفتوحة عند إغلاق المتصفح تلقائياً عند التشغيل القادم.
- **التحكم بالتكبير والتصغير:** تقريب وتصغير محتوى الصفحات (`Ctrl + Plus` و `Ctrl + Minus` و `Ctrl + 0`).
- **وضع الشاشة الكاملة (`F11`):** للاستمتاع بالقراءة والألعاب ومشاهدة الفيديو بملء الشاشة.
- **صفحة الإعدادات الشاملة (`lite://settings`):** لإدارة محرك البحث الافتراضي، الصفحة الرئيسية، مانع الإعلانات، الوضع الخفيف، وتفريغ الذاكرة المؤقتة.

| نظام التشغيل | المحرك ونوع الدعم | الملاحظات |
| :--- | :--- | :--- |
| **Windows XP (SP2 / SP3)** | Native Win32 Subsystem 5.1 + MSHTML / Miniblink | 100% متوافق مع معمارية NT 5.1 دون أي نداءات لـ Vista+ APIs |
| **Windows 7 / 8 / 8.1** | Native Win32 / Win64 + MSHTML IE11 Standards / Miniblink | أداء فائق وسرعة تشغيل فورية |
| **Windows 10 / 11** | Native Win64 / Win32 | تكامل سلس مع وضع المعاينة والشاشة الكاملة |
| **Linux (Ubuntu, Debian, Fedora, Mint, Arch...)** | Native GTK3 + WebKit2GTK (4.1 أو 4.0 عبر التحميل الديناميكي) | دعم كامل لـ HTML5 / WebGL / MSE و Poppler+Cairo |

## 📦 الملفات التنفيذية الجاهزة في مجلد `dist/`

تم بناء الحزم في المجلد `dist/`:

1. **نسخة Linux (64-bit):**
   ```bash
   ./dist/litebrowser-linux-x64
   ```
   أو لفتح ملف مستند مباشرة:
   ```bash
   ./dist/litebrowser-linux-x64 samples/arabic_guide.docx
   ./dist/litebrowser-linux-x64 samples/sample_handbook.pdf
   ```

2. **نسخة Windows XP / 7 / 8 / 10 / 11 (32-بت NT 5.1):**
   - الملف: `dist/LiteBrowser-Win32-XP-7-8-10.exe`
   - يعمل مباشرة بنقرة مزدوجة على Windows XP SP2/SP3 فما فوق دون تثبيت أي حزم.

3. **نسخة Windows 7 / 8 / 10 / 11 (64-بت):**
   - الملف: `dist/LiteBrowser-Win64-7-8-10-11.exe`

> **ملاحظة محرك Chromium على Windows (اختياري):**
> يعمل المتصفح على أنظمة Windows فوراً بالاعتماد على مكتبات النظام القياسية. إذا رغبت بتشغيل محرك Chromium مدمج على Windows XP أو 7، يكفي وضع ملف `node.dll` أو `mb.dll` الخاص بـ **Miniblink** في نفس المجلد، وسيتعرف عليه المتصفح ديناميكياً لتشغيل صفحات الويب الحديثة بأحدث معايير HTML5.

## ⌨️ جدول اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
| :--- | :--- |
| `Ctrl + T` | فتح تبويب جديد (`lite://home`) |
| `Ctrl + W` | إغلاق التبويب الحالي |
| `Ctrl + Shift + T` | استعادة آخر تبويب تم إغلاقه |
| `Ctrl + Shift + N` | فتح تبويب تصفح سري جديد |
| `Ctrl + Shift + B` | إظهار / إخفاء شريط الإشارات المرجعية |
| `Ctrl + F` | البحث عن نص داخل الصفحة الحالية |
| `Ctrl + O` | فتح نافذة اختيار ملف PDF أو Word من الجهاز |
| `Ctrl + L` | تحديد شريط العنوان والبحث للكتابة فوراً |
| `Ctrl + +` / `Ctrl + =` | تكبير محتوى الصفحة |
| `Ctrl + -` | تصغير محتوى الصفحة |
| `Ctrl + 0` | استعادة الحجم الطبيعي 100% |
| `F5` / `Ctrl + R` | تحديث الصفحة الحالية أو إعادة تحميل المستند |
| `F11` | تفعيل / إلغاء ملء الشاشة (Fullscreen) |
| `Escape` | إغلاق شريط البحث داخل الصفحة |
